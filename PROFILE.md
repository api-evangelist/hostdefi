# HostDeFi

Non-custodial, multi-chain DEX interface whose developer product is the HostDeFi Token Risk API — an A+-to-F token safety scoring service across Solana and EVM chains. Exposes a keyless REST API, an x402 pay-per-call agent lane with a live discovery manifest, and a hosted MCP server. Composes Jupiter, KyberSwap, and Chainflip for swaps and bridging.
